# UI directions (design study)

A Slint-only study of three visual directions for the RBS desktop app, made for the
owner's choice on 2026-11-13. It is not part of the app and is not built by the
workspace.

Every picture shown to the owner comes from these files, rendered by Slint itself, so a
direction can be built exactly as shown.

- `ui/look.slint`: the values that differ per direction and theme. Each would become a
  token value in `crates/rbs-ui/tokens.toml`.
- `ui/kit.slint`: one component per job (button, switch, segmented control, dropdown,
  field, slider, row, section header, list row, status line, panel).
- `ui/main.slint`: four screens: main window, Settings > Stream, first run, component sheet.
- `ui/icons.slint`: generated by `gen_icons.py` from `crates/rbs-ui/src/icon.rs`.

Render: `cargo install slint-viewer --version 1.18.1 --locked --features renderer-skia`,
then `./render.sh 2` writes `out/<direction>-<screen>-<theme>.png` at scale 2.
