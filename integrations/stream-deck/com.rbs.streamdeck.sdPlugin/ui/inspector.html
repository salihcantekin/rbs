How do I get a token?
  1. In RBS open Settings, then Remote control.
  2. Turn on Allow remote control.
  3. Make a token with the Control level and copy it.
  4. Paste it above once. All RBS keys share it.

Use a token made only for Stream Deck, so you can revoke it on its own.
