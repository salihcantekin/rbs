# ADR-0011: English for all repository content

- Status: Accepted
- Date: 2026-11-02

## Context

RBS is intended for an international open-source community.

## Decision

All code, identifiers, comments, documentation, specs, ADRs, commit messages, issues and pull requests are written in English. User-facing strings are localised through the i18n system, never hard-coded in another language.

## Consequences

Contributors and AI agents must write in English regardless of the language of the conversation that produced the change.
