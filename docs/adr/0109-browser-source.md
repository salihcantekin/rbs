# ADR-0109: A browser source is CEF in a helper process, one process per Active source

- Status: Proposed
- Date: 2026-11-12
- Deciders: Salih (owner)
- Builds on: [ADR-0006](0006-three-tier-plugin-model.md), [ADR-0016](0016-native-desktop-ui.md), [ADR-0052](0052-ai-agent-control-through-mcp.md), [ADR-0055](0055-crash-resilience.md), [ADR-0106](0106-picture-and-sound-on-one-source.md), [ADR-0107](0107-temporal-sources-sleep-when-hidden.md)

## Context

ADR-0006 puts a browser source in the process tier: CEF, a separate process, shared GPU textures or shared memory, and IPC. ADR-0016 says that process renders web content as video, not as application UI. The plugin host today reads manifests and loads nothing, so there is no general process host to put CEF in.

A page is a temporal picture (ADR-0107): while hidden it must cost nothing, which for CEF means no process. Page audio is picture-and-sound (ADR-0106). A page can fetch the network even from a `file` URL, so the agent rules (ADR-0052) treat it as network-capable. A crash in CEF must not end a recording (ADR-0055).

Click-through into the page, and injecting CSS, are how some tools build overlays. They are a second product (input routing, focus, permissions) and are not required to show a page as a picture.

## Decision

1. **The type is `org.rbs.source.browser`.** Each Active source that holds a slot runs a sandboxed helper tree (its own executable: browser, GPU, renderer, utilities). The studio process must not link or load CEF. This runner is a private adapter the composition root wires. It must not become the plugin process host, and its IPC must not enter the plugin SDK. The plugin SDK may replace the runner later without a scene-format change. The tier choice in ADR-0006 is unchanged.
2. **The process exists only while the source is Active** (ADR-0107). Installed or Standby means no process. A crash must restart that process with back-off and mark the source Unavailable. The studio, recordings, streams, and other sources must keep running (ADR-0055).
3. **Frames cross by a shared GPU texture when the platform can,** otherwise by shared memory and one upload. Control is IPC and carries only `url`, size, and `fps`. `process` must not allocate, block, or talk to CEF.
4. **Settings.** `url` is `https`, `http`, or `file`. `width` and `height` default to 1920×1080, must be even, and must be at most 8192. `fps` defaults to 30. `transparent` defaults to false. The page rate may differ from the canvas; the compositor holds the last frame. A local HTML file is a `file` URL. This decision has no click forwarding and no CSS injection.
5. **Every browser source is network-capable, including a `file` URL,** because the page can fetch (ADR-0052). An agent without the network permission must not set `url`.
6. **Page audio uses ADR-0106.** Samples cross a lock-free queue from a supervisor that is not the render thread, and the node stamps them with the master clock at that edge. A runner that cannot emit samples must not advertise an audio pin. This source must not ship with a pin until ADR-0106 is accepted.
7. **At most two helper trees run.** The cap is global. Program-shown sources take a tree before preview-only ones. Within one class, the lower source id wins. A source that does not get a tree stays without a process and reports Unavailable with reason `browser_cap`; the control API uses that same reason. A crash or hang does not hold a slot while the process is down. ADR-0107 still schedules a visible browser as Active; the missing tree is this cap, not a scene-graph exception. The number two stands until a measurement. ADR-0087 must count one tree per running source.
8. **The studio owns the frame memory.** It allocates the shared texture and the fallback buffer and publishes handles the render thread can drop without touching a dead helper. A crash or a hang (no frame within two of the source's frame periods, supervised off the render thread) marks the source Unavailable and restarts with ADR-0024 back-off. Unavailable keeps the last frame the studio still holds; otherwise the layer is empty. The show keeps running (ADR-0055).
9. **The picture is straight-alpha `Rgba8`, sRGB,** the same pixels a still source uses. `transparent` false forces alpha to opaque before publish; true keeps straight alpha. Both are sent at launch. `fps` defaults to 30 and must be in 1..=60. The fallback upload runs off the render thread and is counted. The consume path needs `hot-path-review` when it lands. `process` must not allocate, block, or talk to the helper.
10. **The page is not an agent.** No JS binding and no RBS API in the page. The helper denies camera, microphone, geolocation, downloads, popups, and persistent permission grants. A `file` URL may read only that file or its directory. Each source has an isolated profile, discarded when its tree stops. A later runner inherits this boundary.
11. **The application UI stays native** (ADR-0016). This source is a picture in the scene. It must not host panels, settings, or the preview.
12. **Checks, without CEF.** Scheme allow list; even size at most 8192; no helper while Standby; cap order prefers program over preview; helper exit and hang leave the host running; the studio drops its buffer without joining a dead child on the render thread; an agent without the network permission gets `not_permitted` for any `url`, including `file`.

## Consequences

- A shown page that holds a slot is one sandboxed helper tree outside the studio. Hiding the item, or leaving its scene off air, stops that tree (ADR-0107). The next show pays CEF startup.
- Two running trees is the cap until a measurement says otherwise. A document may store more browser sources; program-shown sources take the slots first, and the rest report `browser_cap`.
- Spec follow-ups when implemented, at the next free scene-format and protocol minor: scene sources, scene model (temporal class, ADR-0107), user-data, control API, glossary, UI design system, and the plugin SDK with an explicit note that this runner is not the process-tier host. ADR-0052's type list gains this id when the type exists. The capture port stays unchanged: a browser is not OS capture.
- The implementation is blocked on ADR-0106 (decision 6) and ADR-0107 (decision 2) being accepted. It does not wait on a general plugin loader.
- Negative: CEF is large, the first frame is late, and a `file` page is still a network source. Shared-memory fallback is a copy; the GPU-texture path is the one to reach on each platform.
- ADR-0006's process-tier row already names this source. This ADR is the contract; that row's technology choice stays.

## Reference tools (CLAUDE.md rule 17)

- **OBS Studio** ships a Browser Source on CEF in-process with the app: URL, width, height, fps, custom CSS, shutdown when not visible, and an option to refresh and to interact. A crash in that process can take the app down. A hidden source can still be kept alive. Chat overlays are usually this source plus a page the user hosts.
- **Where this falls short of that set:** no interaction, no CSS injection, a hard cap of two Active sources, and no general "browser dock" for the app itself.
- **What RBS does by this decision:** CEF is outside the studio process, so a page crash does not end the show (ADR-0055); a hidden page has no process (ADR-0107, P13); the app UI never becomes HTML (ADR-0016); an agent cannot point the URL somewhere without the network permission (ADR-0052).

## Alternatives considered

- **CEF in-process.** Matches the usual tool and avoids IPC. Rejected: it breaks ADR-0006 and ADR-0055.
- **Wait for the general process-tier plugin host, and ship the browser only as a plugin.** The host loads nothing today. A built-in runner unblocks the source without freezing the plugin ABI. The runner must stay replaceable (decision 1).
- **A silent browser first, audio in a later release.** Rejected by ADR-0106 decision 4: the strip producer would change later.
- **Click forwarding in this decision.** Routing pointer events into a process, with focus and permissions, is a separate contract. A page is a picture here.
- **Treat a `file` URL as local-only.** The document can still `fetch` a host. Fail closed (decision 5).

Verdict: changes requested
Concerns:
1. **Helper death can still fault the studio (ADR-0055, P7).** Decision 2 says a CEF crash restarts that process and the show continues. Decision 3 never says who allocates the shared texture or the shared-memory section. A texture the helper allocates is invalid after the helper dies, and the compositor can fault the studio by sampling it (ADR-0055 class E). A helper that opens the studio's GPU device can reset that device (class F, still unsolved). A hang is not covered: decision 4 holds the last frame indefinitely, the source keeps its Active slot, and nothing restarts it, which misses P7's rule for stalls. -> The studio allocates the texture and the fallback buffer and publishes handles the render thread can drop without touching a dead process. A hang uses the same Unavailable state and ADR-0024 back-off as a crash. The supervisor runs off the render thread. State whether Unavailable keeps the last frame or shows silence until the restart produces one.
2. **"One process" is not a CEF contract, and the studio must stay free of CEF (P1, P13, ADR-0006).** Supported CEF is a sandboxed process tree (browser, GPU, renderer, utilities). One OS process means an unsandboxed single-process mode, and a page compromise then runs with the user's rights. Decision 1 does not name a crate, so `libcef` can be linked into a core or scene crate or loaded into the studio at startup, which costs every user who never adds the source (P13). ADR-0087 counting "one process" undercounts a tree. -> Require a sandboxed helper tree per Active source, started as its own executable. The studio process does not link or load CEF. The runner stays a private browser adapter wired by a composition root; its IPC stays out of the plugin SDK. The cost estimate counts one tree per Active source.
3. **The cap of two contradicts ADR-0107 and can take a page off air.** ADR-0107 decision 2 makes a temporal source Active whenever any shown program or preview scene draws it with `visible` true, union across canvases. Decision 6 forces every further browser source to Standby and does not say which two keep the slots. Preview can fill both slots and put the program page in Standby during a live show. Two canvases that each show two pages need four slots. An unstable choice thrashes CEF startup. The number two has no memory or startup budget (P10). "The UI must say why" does not meet ADR-0052 parity unless the control API reports the same reason. A crashed source that still holds a slot is undefined. -> Amend ADR-0107 with this exception. Fix the cap as global or per canvas, with a stable order that prefers on-air program over preview. Name the control-API state an agent reads. Say whether an Unavailable browser still occupies a slot. Raise the cap only after a named measurement.
4. **The frame and audio crossing is not a contract (P4, P5, P6, ADR-0106).** IPC carries only `url`, size, and `fps`, while settings also include `transparent`. A later runner has no fixed pixel format, alpha mode, or colour space, so replacing it can change the picture without a scene-format change. `fps` has no maximum. Page time is not required to become master-clock time at the edge (P5). Page audio is a ship blocker, but no path is given for samples to reach the ADR-0106 audio pin while `process` neither blocks nor talks to CEF. One upload of an 8192² frame on the render thread is unbounded work (P6), and the CPU fallback is not required to appear in metrics (P4). -> Fix pixel format, alpha, colour space, and a maximum `fps` in this decision. Apply `transparent` at launch or add it to the IPC set. Specify a lock-free handoff into the audio pin with master-clock stamps at the edge. Do the fallback upload off the render thread, or cap that path tighter, and record the copy in metrics. The consume path needs `hot-path-review`.
5. **A loaded page is an unbound network and file agent (ADR-0052).** Decision 5 correctly treats every `url`, including `file`, as network-capable. It does not bound the page. A `file` document can read other local files and `fetch` them. CEF's defaults can prompt for camera, microphone, geolocation, downloads, and popups. A JS binding into RBS would bypass the control API and the agent token. Nothing requires a separate profile per source, so one page can read another's storage. A replacement runner could add those hooks without a scene-format change. -> Make this part of the source contract: no JS bindings and no RBS API in the page; deny camera, microphone, geolocation, downloads, popups, and persistent permission grants; a `file` URL may read only that file or its directory; each source gets an isolated profile discarded when its process stops. A later runner inherits this boundary.
6. **The decision names no checks.** Nothing is named for the scheme allow list, even size and the 8192 cap, no helper while Standby, cap priority, a crash or hang leaving recordings and other sources running, texture lifetime after helper death, or `not_permitted` when an agent sets `url` to a `file` value. -> Name those tests in the decision. Policy tests must not need a real CEF.

Resolutions (author, 2026-11-12), written into decisions 1 and 6–12: (1) the studio owns the texture and the fallback buffer; a hang is Unavailable with ADR-0024 back-off, off the render thread; the last held frame stays, otherwise the layer is empty. (2) A sandboxed helper tree per slot; the studio does not link CEF; IPC stays out of the plugin SDK; the estimate counts one tree. (3) The cap stays two and global; program-shown sources win over preview-only; `browser_cap` is the API reason; a down process holds no slot; ADR-0107 still marks a visible browser Active. (4) Straight-alpha `Rgba8` sRGB, `fps` at most 60, `transparent` at launch, audio on a lock-free queue stamped at the edge, upload off the render thread. (5) No page API; denied device prompts; a `file` URL reads only itself or its directory; one profile per source, discarded on stop. (6) The checks are decision 12 and must not need CEF.
